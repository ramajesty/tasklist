# iPhoneショートカット設定ガイド

iPhoneの「ショートカット」アプリで次の2つを作ります。どちらで追加しても、タスクは**今日期限**で登録されます。

| ショートカット | 使い方 |
|---|---|
| **タスクに追加** | YouTubeやSafariの共有ボタン（□↑）→「タスクに追加」 |
| **音声でタスク** | ホーム画面のアイコン／Siri／背面タップで起動 → しゃべるだけ |

所要時間は合わせて10分ほどです。

---

## 0. 準備（最初の1回だけ）

### 0-1. サーバー側の準備（PCで）
1. Supabase の管理画面で **SQL Editor** を開きます。
2. このフォルダの `supabase/shortcut.sql` の中身を**全部コピーして貼り付け**、**Run** を押します。
3. 「Success. No rows returned」と出ればOKです。

### 0-2. キーを発行する（iPhoneで）
1. ホーム画面の「タスク」アプリを開き、右上のメニュー（≡）を開きます。
2. 「**iPhoneショートカット（共有・音声で追加）**」の「**キーを発行する**」を押します。
3. 「送信先URL」と「キー（token）」が表示されます。**ショートカットを作り終わるまでこの画面は閉じないでください。**
   - 下の手順の途中で「コピー」ボタンを押し、ショートカットアプリに貼り付けます（アプリを行き来してOKです）。
   - 閉じてしまったら「キーを作り直す」で新しいキーを発行すれば大丈夫です（古いキーは使えなくなります）。

> ⚠️ キーは「あなたのタスクに追加できる合言葉」です。人に見せたり、チャットに貼ったりしないでください。

---

## 1. 「タスクに追加」（共有メニューから）

1. **ショートカット**アプリを開き、右上の「**＋**」を押します。
2. 上の名前の部分をタップ →「名称変更」で `タスクに追加` にします。
3. 下の「**ⓘ**」（または画面下の設定）を押し、「**共有シートに表示**」をオンにして「完了」。
   - 一番上に「**ショートカットの入力 を 共有シート から受け取る**」という行が出ます。
   - 「ショートカットの入力」の部分をタップし、**URL** と **テキスト** と **Safari Webページ** にチェックが入っていればOKです（全部オンのままでも大丈夫）。
4. 検索欄で「**URLの内容を取得**」を探して追加します。
   - 「URL」の部分をタップし、アプリでコピーした**送信先URL**を貼り付けます。
   - 「＞」（または「表示を増やす」）を押して詳細を開きます。
   - **方法**: `POST`
   - **本文を要求**: `JSON`
   - 「**＋新規フィールドを追加**」→「**テキスト**」を2回押して、次のように入力します。

     | キー | 値 |
     |---|---|
     | `token` | アプリでコピーした**キー**を貼り付け |
     | `content` | 値の欄をタップ →キーボード上の候補から「**ショートカットの入力**」を選ぶ |

5. 検索欄で「**通知を表示**」を探して追加します。
   - 本文を消して、候補から「**URLの内容**」を選びます（結果が通知で出ます）。
6. 右上の「完了」で保存します。

### 試してみる
YouTubeアプリで動画を開き、「共有」→（一覧の下の方の）「**タスクに追加**」。
初回は「〜へのアクセスを許可しますか？」と聞かれるので「**常に許可**」を選びます。
通知に `{"ok":true,"title":"https://youtu.be/..."}` のように出れば成功です。

- タスクアプリを開くと、少しして**動画のタイトル**に置き換わります（メモにはURLが入ります）。
- 共有メニューに出てこないときは、共有シートの一番下「**アクションを編集**」から「タスクに追加」をオンにしてください。

---

## 2. 「音声でタスク」

いちばん簡単なのは、1で作ったショートカットを複製して直す方法です。

1. ショートカット一覧で「タスクに追加」を長押し →「**複製**」。
2. 複製した方を開き、名前を `音声でタスク` に変えます。
3. 「ⓘ」を押して「**共有シートに表示**」を**オフ**にします。
4. 検索欄で「**テキストを音声入力**」を探して追加し、**一番上**にドラッグで移動します。
   - 「＞」を押して、**言語**を「日本語」、**聞き取りを停止**を「一時停止後」にします。
5. 「URLの内容を取得」の `content` の値を長押し（またはタップ）→「**変数を消去**」し、候補から「**音声入力されたテキスト**」を選び直します。
6. 「完了」で保存します。

### すぐ起動できるようにする（お好みで）
- **ホーム画面に置く**: ショートカットを長押し →「共有」→「**ホーム画面に追加**」
- **Siriで**: 「Hey Siri、**音声でタスク**」
- **背面タップ**: 設定 → アクセシビリティ → タッチ → **背面タップ** → ダブルタップ → 「音声でタスク」
- **アクションボタン**（iPhone 15 Pro 以降）: 設定 → アクションボタン → ショートカット → 「音声でタスク」

## うまくいかないとき

| 通知に出る内容 | 原因と対処 |
|---|---|
| `キーが正しくありません` | キーの貼り間違いか、キーを作り直した。アプリでキーを作り直して `token` に貼り直す |
| `追加する内容が空です` | `content` に「ショートカットの入力」（音声なら「音声入力されたテキスト」）が入っているか確認 |
| `Could not find the function` | 0-1 のサーバー側の準備がまだ。`shortcut.sql` を実行する |
| 通知が出ない／通信エラー | 電波を確認。Supabase が1週間使われず一時停止していないか確認 |

- 追加したタスクは、タスクアプリを開いたとき（同期したとき）に一覧に出ます。
- 「タイトル https://...」のように文字とURLがいっしょに共有された場合は、文字がタイトル、URLがメモになります。
