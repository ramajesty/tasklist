# タスクリスト

自分専用のタスク管理アプリ（PWA）。仕様は [仕様書.md](仕様書.md) を参照。

## 構成（ビルド不要）
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（ダークモード対応） |
| `js/app.js` | 画面の描画と操作 |
| `js/db.js` | 端末内保存（IndexedDB） |
| `js/util.js` | 日付・並び順・リンク化などの共通処理 |
| `js/export.js` | CSV/JSON書き出し・バックアップ復元 |
| `js/recur.js` | 会社カレンダー（稼働日判定）と繰り返しの日付計算 |
| `js/holidays-jp.js` | 日本の祝日の計算 |
| `js/repeat-ui.js` | 編集画面の「繰り返し」欄 |
| `js/calendar-ui.js` | 会社カレンダーの設定画面 |
| `sw.js` | オフライン用サービスワーカー |
| `manifest.webmanifest` / `icons/` | ホーム画面に追加するための設定・アイコン |

## PCで動かす
```powershell
npx --yes http-server . -p 5173 -c-1
```
ブラウザで http://localhost:5173 を開く。

PC内でのテストは別ポート（5174）で行うと、普段使いのデータ（5173）と混ざらない。

## 現在の状態（第2段階まで）
- 実装済み: タスクの追加/編集/完了/削除、並び順、優先、クイック追加（今日期限・`#タグ`可）、メモ（URL自動リンク・`[表示名](URL)`）、画像添付、タグ絞り込み、検索、表示切替（すべて/今日/今週/期限切れ）、完了済み一覧、CSV/JSON書き出し・復元、オフライン動作
- 繰り返し: 毎日/N日ごと、毎週（曜日）、毎月◯日、毎月第N◯曜、**毎月第N稼働日**、**最終稼働日（からN稼働日前）**、毎年
  - 完了すると完了記録を残し、同じタスクが次の期限日で復活（メモ・画像は引き継ぎ）
  - 日・週単位は溜まった過去分を飛ばす／月・年単位は1回分ずつ進む
- 会社カレンダー: 休み曜日、日付タップで休み⇔出勤、祝日一括、期間指定、前年コピー
- 公開URL: https://ramajesty.github.io/tasklist/ （GitHub Pages。`main` に push すると数分で反映）
- クラウド同期: Supabase（タスク・画像・会社カレンダー）。端末内が正本で、ログイン中は自動同期
- iPhoneショートカット: 共有メニュー・音声から今日期限で追加（`supabase/shortcut.sql` ＋ [設定ガイド](docs/iPhoneショートカット設定.md)）。YouTubeのURLはアプリを開いたときに動画タイトルへ置き換え
- カレンダー購読: 未完了タスクの期限日を Googleカレンダー・Outlook に終日予定として表示（`supabase/calendar-feed.sql` ＋ [購読ガイド](docs/カレンダー購読設定.md)）
